# Proposal: main-path-converge

## Why

验证核心闭环与周边能力已基本齐。下一阶段不是再拉长机制，而是把立意做感人：

**愿意天天打开的验证型搭子**——有温度，但「会不会」只认证据；
不与家教 Chat / Anki+LLM / multi-agent demo 同质。

## What changes

1. **归档**已 ship 的活跃夹（Task 0 已做）。
2. **产品故事验收清单**（`design.md` S1–S5）驱动文案/空态/CTA 收敛。
3. **主路径**：打开 → 欠账或添加资料 → 开考/回讲 → 过门芯片 → 收工；
   深挖叙事诚实（练习场，不算掌握）。不改 gate / 排程公式。
4. 工程概念继续躲用户；SYSTEM/README 与故事对齐。

## Out（本波次明确不做）

- 新垂直能力、更深 Agent 平台、全量 MCP 进聊天
- APPLY 完整工作流、Harness UI、自动 adopt
- 为打磨而改 Critic / gate 阈值（除非主路径 bug）

## Success

- S1–S5 验收过关；打开即知下一步
- 深挖不会被理解成「过关」
- 活跃 OpenSpec 仅本夹；无新能力说明书式设置页

## Impact

- 主要：`web/` 文案与空态 / 断点；OpenSpec archive；`docs/SYSTEM.md` 短同步
- 次要：极小 API 文案字段（若有）；**不**扩 core 算法面
