# Daily brief polish

## Why

Empty-thread「今天还欠这些」读起来像一叠扁平灰块浮在空白里：行卡过重、副文过淡、收工/开练与列表脱节。验证入口是脊柱，空态应一眼可读、一点可开考。

## What changes

- `DailyBrief`：iOS 分组列表（一体 soft 底 + 行间 hairline），副文升到 `--muted`，行尾安静「开考」
- Chat 空线程：brief 与收工/开练组成一块 `briefStage`，收窄宽度、收紧间距
- 不改 API / 欠账逻辑 / 开考路径

## Out

- 侧栏、composer、弱点图谱
- 新颜色 token / 响亮描边选中态
