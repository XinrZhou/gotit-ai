# daily-verify-loop

## Why

Personal prep companion: the daily loop is **plan / owed → examine → honest gate**.
Empty chat small-talk and note-only examine (Axiom verdict without Critic/gate)
blur the verify spine. JD-aligned depth should stay personal — not an enterprise
Agent platform.

## What changes

1. **Today brief** on Chat empty states: owed (due claims) + today's plan, each
   with one-tap 开考.
2. **Examine by claim** from plan/due (not only by note).
3. **`/v1/examine` finalize** via Critic recheck + deterministic gate +
   trajectory / mastery writeback (same trust path as thread verify).
4. **Verify trajectory chips** (考 → 核 → 门) on examine turns and gate messages.
