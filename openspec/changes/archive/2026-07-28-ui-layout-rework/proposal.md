# UI layout rework — 资料/验证双栏

> **Archived 2026-07-28** — delivered. 仅前端改动（`web/src/App.tsx` + `web/src/styles.css`），后端零改动。左栏=今日资料（⋯ 菜单），右栏=今日验证（segmented [考我/回讲]），添加入口拆分，空状态引导补齐。

## Why

当前前端是「窄侧栏（队列+笔记混排）+ 主区（考试对话）」，新手看不出「资料 → 检验 → 多轮」的闭环：区域边界模糊、笔记操作直露一个「查看」按钮、「添加测验」与「回讲(Echo)」语义不清。参考 YouMind 的减法与「信息区/创作区分明」哲学，重构为「左资料 / 右验证」双栏，让闭环一眼可见，降低上手成本。

## Scope

- In（前端 only）：
  - 双栏布局：左栏=今日资料，右栏=今日验证
  - 笔记项右侧改 ⋯ 下拉菜单（查看 / 整理成测验 / 删除）
  - 右栏顶部 segmented `[考我 · N] [回讲]`，回讲内联到右栏
  - 拆分添加入口：左栏「+ 添加资料」（手写/链接/文件），右栏考我模式内「+手动加题」「补回顾」
  - 命名与说明文案、空状态引导
- Out：后端 API / MCP / agents / ops / 数据模型（均不动）

## Non-goals

- 链接/文件导入的真实抓取（仍占位）
- 移动端适配
- 记忆/提示词观测页重构

## Delivery notes
