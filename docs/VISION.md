# Vision

**Got it? Prove it.**

gotit-ai stress-tests whether a learner actually understands material — not whether they collected notes.

## Principles

| # | Principle | Meaning |
|---|-----------|---------|
| P1 | Verified = got it | Confidence is not evidence |
| P2 | Fail is useful | A miss becomes a small lesson + recheck |
| P3 | Form follows the claim | Probe, drill, apply, teach-back — pick what tests the idea |
| P4 | Context on a budget | Inject the claim under test, not the whole notebook |
| P5 | Harness-backed evolution | Prompt/skill changes need holdout evidence before adopt |

## Loops

1. **User learning loop:** ingest → claim → examine → (coach → recheck)* → gate → queue  
2. **System evolution loop:** cases → harness → verdict → change → holdout → adopt  
3. **Dev loop:** OpenSpec propose → implement → gate → archive  

## Non-goals (for now)

- Being a second-brain note dump  
- Owning chat channels (OpenClaw does that)  
- Replacing the learner's judgment on *what* to study
